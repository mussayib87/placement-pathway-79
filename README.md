Placement Resource Hub

About the Project

Placement Resource Hub is a student-focused platform designed to bring important placement resources into one place. It helps students access real-world interview experiences, placement resources, and a structured DSA roadmap instead of searching through different sources.

The platform is designed to grow with additional resources such as notes, previous-year question papers, internships, jobs, and other placement preparation materials.

Features

- Real-world interview experiences
- Company-wise placement information
- Technical, HR, and coding interview questions
- Placement preparation resources
- Structured DSA learning roadmap
- Search and filtering
- Responsive student-friendly interface
- Resource management
- Future support for jobs, internships, notes, and previous-year papers

Tech Stack

- Frontend: React + TypeScript + Vite
- Styling: Tailwind CSS
- Backend & Database: Supabase
- Data/API: Supabase JavaScript Client
- Routing: TanStack Router
- State/Data Management: TanStack React Query
- Icons: Lucide React
- Version Control: Git & GitHub
- Deployment: Vercel

Challenge Faced

One challenge was organizing different types of placement information—such as interview experiences, companies, and learning resources—into a clean and easy-to-navigate platform. I had to think about the data structure, user experience, search/filter functionality, and how the platform could be expanded with more resources in the future.

One Improvement

One improvement I would make is adding more personalized features for students, such as a DSA preparation tracker, progress analytics, job and internship recommendations, and a resume section where students can manage their applications.

Future Scope

The platform can be expanded into a complete placement preparation ecosystem where students can learn DSA, access interview experiences and study materials, track their preparation, discover jobs and internships, and manage their placement journey from one platform.
